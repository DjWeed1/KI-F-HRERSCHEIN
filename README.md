# 🚀 KI-Führerschein – Prüfungssimulation

Eine interaktive Multiple-Choice-Prüfungssimulation zur Überprüfung des Wissens rund um Künstliche Intelligenz (inkl. EU AI Act, Prompting, LLMs und ethischen Aspekten). 

Entwickelt für eine Live-Prüfung mit 20 Teilnehmern.

## 📋 Features

- **25 Multiple-Choice-Fragen:** Jede Frage kann mehrere richtige Antworten enthalten (Checkboxen).
- **20-Minuten-Countdown:** Ein integrierter Timer läuft nach dem Start im Hintergrund mit.
- **Start-Button:** Das Quiz und der Timer werden erst nach einem expliziten Start freigeschaltet.
- **Automatischer Alarm & Sperre:** Nach Ablauf der Zeit ertönt ein akustisches Signal, der Test wird automatisch beendet und alle Eingaben werden gesperrt.
- **Sofortige Auswertung:** Zeigt direkt nach der Abgabe die anzahl der richtig beantworteten Fragen an.
- **Single-File-Lösung:** Läuft komplett in einer einzigen `index.html`-Datei ohne externe Abhängigkeiten oder Server-Datenbanken – perfekt gehostet über GitHub Pages.

## 🛠️ Verwendung & Hosting

Das Projekt ist als GitHub Pages Repository konfiguriert und direkt im Browser lauffähig.

1. Repository auf GitHub klonen oder öffnen.
2. Über die GitHub Pages Einstellungen (Branch: `main`, Ordner: `/root`) aktivieren.
3. Den generierten `github.io`-Link an die Teilnehmer verteilen.
4. oder aufrufbar über https://djweed1.github.io/KI-F-HRERSCHEIN/
